# Война Чанков — играбельный прототип

Unity 2022.3 LTS vertical slice: FPS-передвижение, стрельба, карта 5×5 чанков, дерево/камень/золото/алмазы, добыча, крафт, торговля, противники, рейды и захват территорий.

## Запуск
1. Клонируйте репозиторий и откройте папку через Unity Hub в Unity 2022.3 LTS.
2. Дождитесь компиляции. Сцена `Assets/Scenes/Main.unity` создастся автоматически.
3. Откройте сцену и нажмите Play.

## Управление
WASD — движение, Shift — бег, Space — прыжок, мышь — обзор, ЛКМ — стрельба, E — добыча, C — кирка, B — патроны, T — продажа ресурсов, R — рейд. Для захвата стойте рядом с центральной колонной.

Это запускаемый прототип механик, не production MMO. Полная версия потребует серверной архитектуры, БД, аккаунтов, античита, контента и нагрузочного тестирования.
